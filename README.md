# CAKI-Sunitinib
Análise de integração de dados de expressão de mRNA e microRNAs de células CAKI (linhagem celular humana de carcinoma renal).
  
Neste projeto, a análise revelou um componente genomico central na função destas células em resposta a resistencia ao quimioterápico Sunitinib.  
Esta análise possibilitou o redirecionamento de um projeto real, onde passaram a investigar a ação do gene encontrado dentro da sensibilidade destas células ao tratamento
